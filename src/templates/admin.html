Signed in (this tab)

Review listings, block or remove sites, re-check them and change this hub's settings. Every action calls the admin API with your token.

Sign in

Enter the admin token from config.php (admin_token) or the ADMIN_TOKEN environment variable.

The token is kept only in this browser tab (session storage) and is sent as a Bearer header. It is cleared when you sign out or close the tab, and never appears in a URL.

Add a site

Fetches the site's signed profile, verifies it and lists it (or refreshes it if it is already listed).

Re-check due sites

Re-verifies the sites checked longest ago (never blocked ones). A site that fails 7 checks in a row is marked stale. The cron job does the same for every site.

Instance settings

Only fields you change are saved. Clearing the title or description restores the default from config.php.

Maintainer fields are only shown publicly (and only prefilled here) while the badge is on.

Extensions

Turn extensions on with HUB_EXTENSIONS or 'extensions' in config.php.
